## 1. 总体

### 1.1 参照 Unreal

用户迁移成本最低，也和已有的 shell 命名、Enhanced Input 式的输入系统一致。不照搬 Unreal 的地方在各节里写明（例如不留 Redirector，§6.4；撤销按文档分栈，§7.1）。

### 1.2 视觉

- 深色为主，紧凑：普通行高 22–24 px，工具栏 38 px，菜单栏 28 px，状态栏 24 px（与现有 shell 一致）。
- 颜色全部是 `ui_theme` 的 token，现有 shell 的颜色是深色主题的起点；浅色主题是同一组 token 的另一套值。
- UI 缩放 = 显示器 DPI × 用户比例（偏好里设置，例如 80%–150%）。所有尺寸按逻辑像素设计。
- 语义色（全局一致）：选中/焦点 = 蓝（`ACCENT`）；视口选中描边 = 橙；Prefab 实例 = 蓝色文字；覆盖 = 加粗 + 左侧蓝条；新增（实例里添加的 entity）= 绿；断链/丢失/错误 = 红；警告 = 黄；PIE 运行 = 绿边框、暂停 = 黄边框。

## 2. 窗口、docking 和布局

### 2.1 结构

- 主窗口里是一排**顶层 tab**：第一个是 Level Editor，之后每打开一个资产编辑器（Prefab、材质…）就多一个顶层 tab。顶层 tab 可以拖出成独立的 OS 窗口（走 Host 的多窗口，0019 §13.1）。
- 每个顶层 tab 内部是自己的 docking 树：节点是水平/垂直分割或 tab 组，叶子是面板。
- 面板可以拖到另一个 tab 组、拆分出新的组、或拖出成浮动 OS 窗口。

### 2.2 拖放

- 拖动面板 tab 时，目标 tab 组中央出现**十字靶标**：上、下、左、右、中 5 个落点；整个顶层 tab 边缘另有 4 个全局落点（贴边占满一侧）。
- 悬停落点时，用半透明蓝色矩形预览放下后的区域。拖到靶标之外松开 = 浮动窗口。
- 在 tab 栏内左右拖动只是重排顺序。

### 2.3 tab 栏

- tab 组里只剩一个面板时**仍然显示 tab 栏**，保证随时可拖。
- tab 右键：关闭、关闭其他、隐藏 tab 栏（隐藏后左上角留一个小三角，点击恢复）。
- 双击 tab 或按 **F11**：把这个面板临时最大化撑满当前顶层 tab，再按一次恢复。这是小屏幕扩大视口的唯一方式（不做抽屉式自动隐藏，也不做沉浸模式）。

### 2.4 持久化

- 布局按**用户**保存在用户目录，与项目无关，不进版本库。
- 关掉的面板记住最后所在的 dock 节点；从 Window 菜单重开时放回原位置，原节点没了就浮动在主窗口中央。
- 不做命名布局预设。Window 菜单里有“重置为默认布局”。

### 2.5 默认布局（Level Editor）

```
┌ 菜单栏 ───────────────────────────────────────────────────────────────┐
├ 主工具栏：[保存][+ 添加▾] ……… [▶▾][⏸][■] ……… [Cook▾][平台▾][Tier▾] ┤
├──────────────┬──────────────────────────────────────┬──────────────────┤
│ Outliner     │ Viewport 1                           │ Details          │
│  | Levels    │                                      │  | World Settings │

│ 状态栏：当前子关卡 · 后台任务 · ✖ 2 ⚠ 5                                │
└────────────────────────────────────────────────────────────────────────┘
```

## 3. 场景视口

### 3.1 相机导航

| 操作 | 行为 |
|---|---|
| 右键按住 + WASD/QE | 飞行（已有，`marlin_gameplay::fly`）。按住右键时**滚轮调飞行速度档位**，视口角落短暂显示当前档位 |
| Alt + 左键拖 | 环绕：绕选中物（无选中时绕光标下的表面点）旋转 |
| Alt + 中键拖 / 中键拖 | 平移 |
| Alt + 右键拖 | 推拉 |
| 滚轮 | 朝**光标指向的表面点**推进（不是屏幕中心）；指向天空时朝视线方向 |
| F | 聚焦选中物：约 0.25 s 缓动飞过去，保持当前朝向，距离使包围球占视野约 70%；之后环绕中心设为该物体 |

- 在视口里按住右键时，即使键盘焦点在别的面板，视口也临时拿到焦点；松开后焦点留在视口（§9.3）。
- 不做相机书签。

### 3.2 视口工具栏（视口左上角）

- **视图模式**：Lit / Unlit / Wireframe / Lit+Wire，以及渲染调试视图（albedo、normal、roughness、光照、ReSTIR/SHaRC/降噪中间结果），后者接 render graph 的可视化通道。
- **Show flags**：网格、包围盒、光源图标、组件可视化、子关卡边界、碰撞等叠加的开关。
- **投影**：透视 / 前后左右顶底正交；FOV、近远裁剪、相机速度。
- 右侧：移动/旋转/缩放切换、World/Local、三个吸附开关和步长下拉（§3.4）。

### 3.3 选择

- **点选**：选中 Prefab 实例的根（即使点到的是内部网格）；**双击**逐层进入，选中内部的子 entity；**Alt+点击**在重叠的物体间循环。
- **框选**：左键在空处拖动即框选，**相交即选**；视口选项里可切“只选可见”（基于 ID buffer，忽略被遮挡的）。
- **修饰键**（视口和 Outliner 一致）：Shift = 加选，Ctrl = 切换，Ctrl+Shift = 减选。Alt 留给相机。
- 被锁定（§4.4）的 entity 在视口里不能点选或框选。
- **高亮**：选中物屏幕空间描边，主选中物亮橙、其余暗橙；被遮挡的部分描边变淡；悬停时细蓝边（预选中）。

### 3.4 变换 gizmo 和吸附

- W 移动 / E 旋转 / R 缩放，分开显示：
  - 移动：三轴、双轴平面方块、中心方块在屏幕平面拖动。
  - 旋转：三个轴环加屏幕空间外圈。
  - 缩放：三轴加中心均匀缩放。
  - 拖动时在 gizmo 旁显示数值增量（Δ 1.25 m、Δ 45°）。
- 坐标系：World / Local 切换（工具栏按钮 + 快捷键）；多选时枢轴可选“选择中心”或“主选中物”。
- 吸附：网格 / 角度 / 缩放步长三个开关和步长下拉；拖动中按住 Ctrl 临时反转吸附。
- 表面吸附：拖动时贴合光标下的表面，可选对齐法线；**End** 把选中物落到下方表面。
- 不做顶点吸附。

### 3.5 组件可视化

- 没有网格的 entity（光源、相机、触发器…）用固定屏幕大小的图标 billboard，可以点选；光源图标着光色。
- 选中时显示影响范围：点光半径球、聚光锥、相机视锥、体积线框。
- 组件可以声明可拖动的手柄（光源半径、聚光角度、盒体积的面），由组件的反射元数据或脚本声明；视口里直接拖。

### 3.6 常驻叠加

- 左下角方向轴：可点击，点轴切换到对应正交视角。
- 帧率和 GPU 时间（可关）：点开展开各 pass 的时间，接 dev overlay。

### 3.7 多视口

- 视口是普通面板，最多 4 个（Window → Viewport 1–4），各自有相机、视图模式和 show flags，由 docking 自由摆放。
- 每个视口对应 0019 §13.2 的一个 `SceneViewport`，视图目标是各自的 `Offscreen(id)`。

## 4. Outliner

### 4.1 行

- 行首：眼睛（可见）、锁（不可选）。
- 图标按主要组件（网格、光、相机、空 entity、文件夹、子关卡）。
- 名字；可加列：类型、子关卡、Prefab 来源、标签（列头右键选择）。
- 状态：Prefab 实例名字蓝色；有覆盖的行右侧圆点；链接断了红色；实例里新加的 entity 绿色；git 状态角标（§7.4）。

### 4.2 树结构

- 顶层是子关卡，当前编辑目标加粗（§10.2）。
- 子关卡内可以建**编辑器文件夹**：只用于整理，不生成 entity，存在关卡源数据的编辑器部分。
- 文件夹下是 Transform 父子层级。
- Prefab 实例可展开：内部原有的 entity 灰色显示，不能删除或改层级（§11.2）。

### 4.3 搜索

- 名字模糊搜索：匹配的行高亮匹配字符，祖先行灰色保留，保持树形。
- 结构化查询：`t:Light`、`c:RotatingMovement`、`prefab:Door`、`level:Interior`，可与文本组合，空格是“与”。

### 4.4 操作

- **拖动改父级**：拖到行上半/下半显示排序插入线，拖到行中间显示挂接框；默认**保持世界位置**，按住 Alt 放下则保持局部变换；拖到子关卡行 = 移到那个子关卡。
- **眼睛和锁**是纯编辑器状态，只影响编辑视口（不影响游戏和 PIE），存在用户侧，不进源数据。游戏里的可见性是组件属性，在 Details 里改。
- **改名**：F2 或慢双击就地改名。名字只是显示用，身份是 `EntityGuid`，可以重名；复制时自动加后缀 `_2`。多选按 F2 打开批量重命名（前缀、编号、查找替换）。
- **右键菜单**（视口和 Outliner 共用）：
  - 编辑：剪切、复制、粘贴、重复（Ctrl+D）、删除、重命名、聚焦。
  - 组织：新建文件夹、移到子关卡…、脱离父级、选中所有子级。
  - Prefab：从选中创建 Prefab、打开 Prefab、就地编辑、应用覆盖到 Prefab、还原覆盖、解除链接（展开）、替换为另一个 Prefab。

## 5. Details

### 5.1 结构

- **头部**：图标、名字（可改）、Guid、Prefab 来源（可点击打开）、“覆盖 (N) ▾”（§11.2）。
- 属性搜索框：按属性名过滤，匹配的分区自动展开。
- 每个组件一个可折叠分区；Transform 固定在最上；分区标题右侧有菜单（重置、复制组件、粘贴组件、删除组件）。
- 底部“+ 添加组件”：带搜索的弹出列表，按类别分组，包括脚本组件。
- 一个面板只显示当前选择，不做锁定/多开 Details。

### 5.2 多选

- 只显示所有选中物都有的组件（交集）。
- 值不同的字段显示“—”；修改会写入全部；数值字段拖动时各自加增量，输入时统一赋值。

### 5.3 数值字段

- 在字段上左右拖动改值，光标隐藏并无限滑动；Shift 精细、Ctrl 粗调；单击进入文本输入。
- 表达式输入：`*2`、`+10`、`90/4`，带单位：`1m`、`30cm`、`45deg`。
- 向量：XYZ 字段左侧 R/G/B 色条，在色条上拖动单轴；缩放有“锁定比例”按钮。
- 文本提交规则见 §12.4。

### 5.4 状态和行操作

- 非默认值行尾显示 ↶，重置为默认值。
- Prefab 实例：覆盖的字段名加粗、左侧蓝条，↶ 还原到 Prefab 的值。
- 右键：复制/粘贴属性；复制为文本（源格式片段），可以跨 entity 粘贴。
- tooltip 规则见 §12.3。

### 5.5 特殊字段

- **资产引用**：左侧 48 px 缩略图 + 名字下拉（弹出带搜索、按类型过滤的资产选择器）+ ↵（使用 Content Browser 当前选中）+ 🔍（在 Content Browser 定位）；可以从 Content Browser 拖入；引用丢失时红色。
- **Entity 引用**（`EntityRef`）：下拉搜索 + 吸管：吸管模式下光标变吸管，在视口或 Outliner 里悬停的合法目标高亮，点击选定，Esc 取消；也可以从 Outliner 拖入；跨子关卡的引用显示子关卡名。
- **旋转**：显示欧拉角（度），内部存四元数；editor 记住用户输入的欧拉角（编辑器侧数据），输入 360 不会变成 0，也不会因万向节问题数字跳变。
- **数组**：标题行显示“3 项”和 ➕ 🗑；每行左侧抓手拖动排序，行尾菜单：插入、复制、删除。
- **颜色**：色块，点击弹出拾色器（色轮/色方、RGB/HSV/Hex、屏幕吸管、最近使用）；区分线性和 sRGB；HDR 颜色有强度滑条，光源使用 lux/lm 单位（R3b）。
- 枚举用下拉。

## 6. Content Browser

### 6.1 结构

- 左侧文件夹树：顶层是挂载点（Engine 只读、Game），0003 §4.5。
- 顶部面包屑：每段可点，段间箭头下拉列出同级文件夹；前进/后退按钮和鼠标侧键。
- 右侧资产网格，缩略图大小滑条，可切列表视图。

### 6.2 资产格子

- 缩略图 + 底部类型色条（网格蓝、材质绿、Prefab 紫、关卡橙…）+ 名字。
- 角标：未保存（*）、cook 失败、源文件丢失、git 状态。
- 悬停 tooltip：路径、大小、引用数、cook 状态。

### 6.3 缩略图

- 网格、材质、Prefab 由后台用 `RenderScene` 渲染，缓存在本地（项目的 DDC，不进版本库）。
- 右键“用当前视角捕获缩略图”：这张图存进资产的源数据，覆盖自动缩略图。

### 6.4 搜索

- 文本搜索 + 搜索框下一排类型过滤片（Mesh / Material / Prefab / Level / Texture / Script…）。
- 默认递归搜索当前文件夹，一个按钮切到全项目。
- 元数据查询：`tris>10000`、`unused`、`modified:today`、`tag:foliage`，语法与 Outliner 的查询一致。

### 6.5 操作

- **导入**：把外部文件（fbx/gltf/png…）拖进 Content Browser，弹出导入设置：左侧文件列表，右侧选项（缩放、法线、是否创建材质…），可“全部应用”。设置存为资产的 import 数据；源文件改变后可一键 Reimport。导入进度在状态栏后台任务区。
- **拖入视口**：拖进视口立即生成半透明预览，贴在光标下的表面上（底部对齐），松开放置，Esc 取消。网格 → 带 MeshRenderer 的 entity；Prefab → 实例；材质拖到物体上 → 替换那一处的材质（目标物体高亮）。
- **改名/移动**：立即改写所有引用者的源文件。引用里已经有 UUID，改写的是路径部分；改写前弹窗列出将被修改的文件让用户确认。不留 Redirector。
- **删除**：没有引用直接删除，可撤销（文件进系统回收站）；有引用时弹窗列出引用者，可以“替换为…”（选一个替代资产）或强制删除。

## 7. 撤销、保存和版本控制

### 7.1 撤销

- **每个文档一个撤销栈**：关卡、每个打开的资产编辑器各一个；Ctrl+Z / Ctrl+Y 作用于当前焦点所在的顶层 tab。
- Content Browser 的文件操作（移动、改名、删除）有自己的栈，焦点在 Content Browser 时生效。
- 一次撤销 = 一次用户操作：一次 gizmo 拖动、一次字段提交、一次粘贴。

### 7.2 选择和撤销

- 选择变化进撤销历史，连续的选择合并成一步；Ctrl+Z 会先恢复上一个选择。
- 只改选择不把文档标记为已修改。

### 7.3 保存

- 修改只在内存里；顶层 tab、Content Browser 格子和 Levels 面板显示“*”。
- Ctrl+S 保存当前文档；Ctrl+Shift+S 弹出“保存全部”的勾选列表。
- 每 N 分钟（偏好）把所有未保存文档写一份到 `Saved/Autosave`；崩溃后下次启动提示恢复。自动保存不写源文件。
- 退出或关闭有未保存修改的 tab 时弹模态对话框：保存 / 不保存 / 取消。

### 7.4 版本控制

- 只显示 git 状态：Content Browser 和 Outliner（子关卡行）的角标表示修改、新增、冲突。
- 外部修改了正在编辑且未保存的文件时，弹出“重新加载 / 保留我的”选择；没有未保存修改就直接重新加载（已有：0019 W5 的源文件检查）。
- 提交、diff、锁在外部工具里做。

## 8. Play In Editor

### 8.1 启动

- ▶ 旁的下拉：在当前视口 / 在新窗口（分辨率或设备预设）；从当前相机位置开始 / 从玩家出生点开始。默认在当前视口。
- Alt+P 或 ▶ 开始，再按 Alt+P 或 ■ 结束（已有）。

### 8.2 状态提示

- 运行中视口有绿色边框，暂停时黄色。
- 工具栏变为 ⏸ ⏭（单帧）■。
- 开始时弹一个会自动消失的提示：“Shift+F1 释放鼠标”。

### 8.3 运行时查看和修改

- PIE 期间 Outliner 和 Details 切到 Pie World：显示运行时 entity，包括动态 spawn 的（斜体）。
- Details 改值实时生效，不保存；结束 PIE 时丢弃。
- 字段右键“保留此改动”：把这个属性写回编辑文档（只对源关卡里有的 entity）。

### 8.4 Eject

- F8：游戏继续运行，视口切到编辑器相机，可以选中和用 gizmo 移动 PIE 里的物体；再按 F8 回到玩家。

## 9. 命令、快捷键和焦点

### 9.1 命令都是 input action

- 每个命令是一个 input action，沿用 `Editor.masset` 的 action + mapping context；上下文 = 焦点所在的面板（视口、Outliner、Content Browser…），外加全局上下文。
- 偏好里有快捷键编辑器：搜索、按键录制、冲突提示；用户的改动存在用户目录。

### 9.2 命令面板

- Ctrl+P 打开。默认搜资产；前缀 `>` 命令、`@` entity、`#` 设置。
- 每条结果显示快捷键；所有菜单项都是可搜索的命令。

### 9.3 焦点

- 点击设置键盘焦点；焦点面板顶边有细蓝线。快捷键发往焦点面板的上下文。
- 例外：在视口里按住右键飞行时，视口临时获焦，松开后焦点留在视口。

### 9.4 默认快捷键

| 键 | 上下文 | 命令 |
|---|---|---|
| W / E / R | 视口 | 移动 / 旋转 / 缩放 |
| F | 视口、Outliner | 聚焦选中物 |
| End | 视口 | 落到下方表面 |
| Ctrl+D | 视口、Outliner | 重复 |

| Ctrl+Z / Ctrl+Y | 全局 | 撤销 / 重做（当前文档） |

| F11 | 全局 | 最大化焦点面板 |

| Shift+F1 | PIE | 释放鼠标（已有） |
| F8 | PIE | Eject |

## 10. 其他 Level Editor 面板

### 10.1 主工具栏和状态栏

- 主工具栏：左侧保存、“+ 添加▾”（空 entity、光源、相机、基本形体、最近使用的 Prefab）；中间 ▶▾ ⏸ ■；右侧 Cook/Build、目标平台、画质 tier（R4f 的预设）。
- 状态栏：左侧当前编辑的子关卡；中间后台任务区（“编译 shader 3/40”，点开任务列表）；右侧 ✖ 错误 ⚠ 警告计数，点击打开 Output Log 并按级别过滤。
- 右下角 toast：保存成功、导入完成、cook 错误等；长任务带进度条和取消；错误不自动消失，点击跳到日志。

### 10.2 Levels

- 列出子关卡：当前编辑目标（新建的 entity 放这里，粗体）、加载/卸载、可见、锁定、色标、未保存状态。
- 双击设为当前；视口里可以按子关卡色标着色（show flag）。
- Outliner 顶层的子关卡行和 Levels 面板是同一份状态。

### 10.3 World Settings

- 独立面板，默认和 Details 在同一个 tab 组；编辑 `LevelSettings`（环境、默认游戏模式…），用 Details 同款属性编辑器。

### 10.4 Place

- 按类别（基础、光源、相机、体积、最近、脚本）列出可拖入视口的模板，拖入的行为同 §6.5。
- 视口右键“在此处添加…”：放在点击处的表面上。
- 新建的 entity 自动选中并进入重命名。

### 10.5 Output Log

- 接 `marlin-diag`：级别开关、类别多选、文本搜索高亮。
- 自动滚到底；向上滚动时暂停，显示“↓ 新消息”。
- 日志里的资产路径、entity、源文件行号可点击跳转，依赖统一的错误/报告设计（[0023](0023-errors-and-logging.md) §2.4 `Issue`、§3.4 `Subject`）。

### 10.6 设置

- 两个窗口：Editor Preferences（存用户目录）和 Project Settings（存 `.mproject` 和项目的配置资产）。
- 左侧分类树 + 右侧 Details 同款属性编辑器 + 顶部搜索；与默认值不同的项有 ↶。

### 10.7 启动

- editor 只从 `.mproject` 启动（命令行参数，或双击 `.mproject` 经 launcher 转过来）；不带参数时报错并提示用 launcher。项目浏览器、新建项目和引擎版本选择在独立的 `marlin-launcher` 里（0021 §13）。
- 进入后恢复上次打开的关卡和资产 tab。
- 启动进度显示在 splash 上。

## 11. 资产编辑器

### 11.1 统一外壳

- 每个资产编辑器是一个顶层 tab（§2.1），内部有自己的 docking 布局。
- 固定工具栏：保存、在 Content Browser 中定位、引用查看器；其余按钮由编辑器自己加。
- 常见面板：预览视口（Preview World 或直接 `RenderScene`，0019 §13）、Details、各自的面板。
- 没有专用编辑器的资产类型自动用通用的“反射 Details”编辑器。

### 11.2 Prefab

- 两个入口：
  - 在 Content Browser 双击：打开 Prefab 编辑器（Preview World，自己的 Outliner/Details/视口，交互同 Level Editor）。
  - 在关卡里选中实例 → “就地编辑”：其他物体变灰且不可选，视口顶部出现面包屑条“关卡 › Door”和保存/退出；改动即时反映到所有实例。
- **覆盖**：Details 头部“覆盖 (N) ▾”下拉列出所有覆盖的 entity/组件/字段，每项可“应用到 Prefab”或“还原”，底部“全部应用 / 全部还原”；嵌套 Prefab 时可选应用到哪一层。
- **结构覆盖**：实例里允许添加子 entity（绿色），不允许删除原有的；原有的只能隐藏或禁用。这样实例和 Prefab 的结构对应关系保持稳定。
- **从选中创建**：弹保存对话框，可选枢轴（包围盒底部中心 / 主选中物 / 世界原点），多选时自动建根 entity；原物体替换为实例。也可以从 Outliner 拖到 Content Browser 创建。

### 11.3 材质

- 材质本身写 Marlin shader 代码，不做节点图。代码只在外部 IDE 写，editor 里没有代码视图（0021 §9.4）；Content Browser 双击用外部编辑器打开，保存即重新编译并热重载，错误进 Output Log 并可跳转。
- 材质实例编辑器：参数面板（由材质参数自动生成）+ 预览球体/网格，改参数实时反映。

### 11.4 网格和纹理查看器

- 预览 + 导入设置 + 统计（三角形数、LOD、mip、格式）+ Reimport。

### 11.5 脚本

- `.mscript` 在外部 IDE 写；Content Browser 双击用外部编辑器打开（偏好里设置）。
- 保存自动编译，错误进 Output Log 并可跳转；提供 LSP。
- 脚本组件的字段自动出现在 Details 里。

## 12. 通用控件规范

### 12.1 语言

- 英文为主，所有字符串走本地化表；中文第二个做。
- 布局给文本变长留余量，不按英文宽度写死；CJK 字体回退。

### 12.2 对话框

- 尽量不用模态。模态只用于：导入设置、改名/移动的引用确认、有引用的删除、未保存退出。模态对话框居中、背景变暗、Enter 确认、Esc 取消。
- 其余用弹出层（popover）或 toast；可以撤销的操作不确认（例如删除没有引用的东西）。

### 12.3 Tooltip

- 第一个 tooltip 悬停 0.5 s 后出现；之后在相邻控件之间移动立即切换。
- 内容：名称 + 快捷键；悬停时按 Ctrl 展开详细内容（文档注释、类型、默认值）。

### 12.4 文本输入

- Enter 或失焦提交，Esc 还原；一次编辑产生一条撤销记录。
- 拖动数值期间实时预览，松手时产生一条撤销记录。
- 数值字段里 ↑ ↓ 微调。
