# samples/basic

The smallest Marlin game: one level (`levels/main.masset`) with a fly camera, a ground slab, a
sphere, a spinning torus and a ring of spinning cubes, plus a texture that is cooked and loaded
(the forward renderer does not sample textures yet).

## Running it

The engine's own content (its shaders, `content/engine`) is a package of its own, which
`boot.toml` mounts below the sample's; cook and package it first:

```
cargo run -p marlin-cooker --bin marlin-cook -- cook content/engine
cargo run -p marlin-cooker --bin marlin-cook -- package content/engine
```

From a packaged build:

```
cargo run -p marlin-cooker --bin marlin-cook -- cook samples/basic
cargo run -p marlin-cooker --bin marlin-cook -- package samples/basic
cargo run -p marlin-game -- samples/basic/boot.toml
```

Live, from the cook service (edits to the `.masset` files and their sources show up in the
running game; the engine package still comes from `content/engine`):

```
cargo run -p marlin-cookd -- samples/basic
cargo run -p marlin-game -- samples/basic/boot.toml +content.package "" +content.cookd 127.0.0.1:47200
```

Right mouse button + mouse, or the right stick: look. WASD or the left stick: move. Q/E or the
triggers: down/up. Shift: faster. V: vsync. F11 or Alt+Enter: fullscreen. Esc: quit.

## Where the binary files come from

`meshes/*.glb` (a 1-unit cube with flat faces, a 0.5-radius UV sphere and a torus) and
`textures/checker.png` were generated by a small throwaway program and committed as content.
Regenerate or replace them freely: the `.masset` files only refer to them by path, and cooking
picks up changes by content hash.
