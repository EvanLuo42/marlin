# Interop fixtures

Frames written by the reference implementations, decoded by `tests/unit/interop.rs`. Generated once
with a throwaway program linking the reference C libraries; nothing here is a build or test
dependency.

| directory   | reference                                                                    |
|-------------|------------------------------------------------------------------------------|
| `zstd/`     | libzstd 1.5.7                                                                |
| `lz4/`      | liblz4 1.10.0 (`.lz4` = frame format via LZ4F, `.lz4b` = raw block)          |
| `gdeflate/` | NVIDIA's libdeflate GDeflate fork as shipped with DirectStorage, in the DirectStorage `TileStream` container |

Names are `<shape>-<size>-<seed>-<settings>`: the input is `tests/support` shape `<shape>` of
`<size>` bytes from `<seed>`, regenerated by the test. `zstd/multi-frame.zst` is
`text(50000, 7)` at level 3 with checksum, a 5-byte skippable frame, then
`binary(30000, 8)` at level 7. `-stream` frames were written without a pledged size, so they
have a window descriptor and no content size.
